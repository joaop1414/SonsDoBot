# SonsDoBot

Sons curtos originais para o comando `!som nome` do YouTube Chat Bot.

## Catálogo

| Comando | Preço | Descrição |
|---|---:|---|
| `!som boom` | 20 moedas | Grave e impactante, efeito original de meme |
| `!som risada` | 10 moedas | Risada eletrônica curta e divertida |
| `!som aplausos` | 15 moedas | Palmas sintéticas originais |
| `!som level-up` | 15 moedas | Sequência ascendente estilo videogame |
| `!som erro` | 5 moedas | Efeito retrô de erro de jogo |
| `!som suspense` | 20 moedas | Tom crescente de suspense |

Os efeitos foram sintetizados especialmente para este repositório; não são gravações de músicas, filmes ou jogos comerciais.

Os preços ficam em `precos.json`. O bot carrega os arquivos de áudio da raiz do repositório.
